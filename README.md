# Plan your Submission
A tiny questionnaire web app for RDM support; follow the questions and receive an estimation on how long your submission could take. How much in advance you should contact bigdatacore about your intention to submit, and a checklist of information.

# Files
- 'Index.html' - questionnaire and result screen
- 'style.css' - styling
- script.js' - scoring, estimate calculation and checklist
